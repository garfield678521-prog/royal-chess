# ♟️ Royal Chess

A complete browser-based chess game built with **HTML, CSS, and JavaScript**.

Royal Chess is designed to run directly on **GitHub Pages** with no server, database, Node.js, npm, or external libraries required.
(use here https://garfield678521-prog.github.io/royal-chess/)

---

## 🎮 Features

Royal Chess includes the major official chess rules and move types.

### ♟️ Chess Pieces

- King
- Queen
- Rook
- Bishop
- Knight
- Pawn

### 🏃 Move Types

- Normal piece movement
- Captures
- Pawn first double move
- Pawn diagonal captures
- Knight jumping
- Sliding movement
- King movement
- Castling
- En passant
- Pawn promotion

### 👑 Special Rules

- Kingside castling
- Queenside castling
- En passant
- Promotion to:
  - Queen
  - Rook
  - Bishop
  - Knight

### ⚔️ Game Rules

- Check detection
- Checkmate detection
- Stalemate detection
- Legal move validation
- King safety
- Threefold repetition
- 50-move rule
- Insufficient material
- Draw by agreement
- Resignation
